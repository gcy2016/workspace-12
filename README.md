# 小橘狐大冒险

一个原创形象的横版卷轴跳跃网页游戏，玩法致敬经典平台跳跃游戏：画面跟随角色向右滚动，顶砖块拿金币和道具，吃蘑菇变大、吃火焰花放火球，踩敌人，冲向终点旗杆。

- 3 个关卡：1-1 草原、1-2 地下洞穴、1-3 黄昏树梢，每关有中途检查点
- 敌人：咕噜（踩扁）、硬壳虫（踩成壳后可以踢出去撞飞别的敌人）
- 纯前端单文件 `index.html`，无需安装，直接用浏览器打开即可
- 支持电脑键盘和手机触屏（横屏体验更好）

## 操作

| 动作 | 键盘 | 手机 |
|---|---|---|
| 移动 | ← → / A D | ◀ ▶ |
| 跳（长按跳得更高） | 空格 / Z / ↑ | 跳 |
| 冲刺 / 火球 | X / Shift | 冲刺火球 |
| 暂停 | 回车 / P | — |
| 静音 | M | 🔊 按钮 |
